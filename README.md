# HERRERA AUTO SALES — Sistema de Gestión

Aplicación web SPA funcional para administrar una operación de intermediación y comercialización de vehículos.

## Stack
- React + Vite
- Lucide React
- CSS propio, sin Bootstrap
- LocalStorage para persistencia local

## Funciones implementadas
- Login local
- Dashboard KPI
- CRUD de vehículos
- Estados de vehículos
- Búsqueda global
- Filtros y ordenamiento
- Cálculo automático de comisiones
- Ficha individual del vehículo
- Propietarios
- Interesados / compradores
- Seguimientos
- Registro de ventas y estado de comisión
- Reportes con gráficos
- Documentos con carga/descarga local
- Configuración
- Exportación de respaldo JSON
- Restauración de datos demo
- Diseño responsive

## Ejecutar
Requiere Node.js 18+.

```bash
npm install
npm run dev
```

Abrir la URL que indique Vite.
